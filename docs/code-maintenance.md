# 백엔드 코드 안내 및 정리 기준

## 기능별 구조

모든 경로는 `src/main/java/com/rufit/` 기준입니다. 각 패키지의 `package-info.java`에서 기능의 범위와 주의점을 먼저 확인하실 수 있습니다.

| 패키지·파일 | 역할 | 수정 시 확인 사항 |
| --- | --- | --- |
| `auth/LoginAttempts.java` | 소셜 로그인 시작·콜백·일회성 교환을 조율합니다. | PKCE/state/nonce, 만료, 요청 제한과 중복 소비 방지를 함께 유지해야 합니다. |
| `auth/AuthSessions.java` | 계정·세션 발급, 인증, 갱신과 폐기를 처리합니다. | 트랜잭션 경계, 토큰 재사용 감지, 세션 폐기 시점을 확인해 주세요. |
| `auth/ProviderGateway.java` | 외부 로그인 제공자의 인증 증명을 확인합니다. | 클라이언트가 보내는 사용자 식별자를 검증 없이 신뢰하지 않아야 합니다. |
| `workout/Workout.java` | 운동의 진행·일시정지·완료와 세트 상태를 관리합니다. | 경과 시간, 세트 범위와 상태 전이 규칙을 유지해야 합니다. |
| `workout/WorkoutService.java` | 소유권 검사, 조회, 시작, 변경, 가져오기를 조율합니다. | 계정당 진행 중 운동 제한, 요청 식별자와 변경 버전의 의미를 구분해 주세요. |
| `workout/DraftOperations.java` | 적용한 초안 작업의 식별자와 버전을 보관합니다. | 같은 작업의 재시도가 중복으로 적용되지 않아야 합니다. |
| `workout/WorkoutCalendar.java` | 시간대에 따른 월간·주간 운동 기록을 집계합니다. | 날짜 범위와 SQL 집계가 같은 시간대 기준인지 확인해 주세요. |
| `exercise/ExerciseService.java` | 공통·사용자 종목을 검색하고 사용자 종목을 관리합니다. | 소유권과 수정 버전, 검색 정규화 규칙을 확인해 주세요. |
| `exercise/ExerciseRestService.java` | 권장·개인별 휴식 설정을 제공합니다. | 추천 복귀 후에도 오래된 요청이 새 설정을 덮어쓰지 않아야 합니다. |
| `routine/` | 루틴 저장·수정과 루틴 기반 운동 시작을 처리합니다. | 원본 루틴과 시작된 운동의 세트는 독립적으로 관리되어야 합니다. |
| `profile/` | 프로필과 공통 휴식 설정을 관리합니다. | 인증 소유권을 기준으로 접근해야 합니다. |
| `common/`, `config/` | 공통 오류·추적·입력·보안·API 문서를 구성합니다. | 실행 프로필별 인증 조건과 민감 정보 비노출을 유지해야 합니다. |

## 요청 처리의 경계

컨트롤러는 요청을 받고 인증 계정과 입력을 서비스에 전달합니다. 서비스는 소유권·버전·재시도 규칙을 확인하며 도메인과 저장소를 조율합니다. 도메인은 상태 전이와 데이터 제약을 지키고 저장소는 영속성과 조회를 담당합니다. 이 책임을 옮길 때에는 기존 트랜잭션 범위와 인증 검사를 함께 검토해 주세요.

최근 프론트에서 추가한 삼대·체중·수동 과거 기록·완료 달성률 화면은 현재 기기 내 저장을 사용합니다. 이번 코드 정리에서는 해당 기능의 서버 API를 새로 만들거나 연결하지 않았습니다. 기존 서버 API 계약은 `docs/api-contracts/`를 기준으로 확인해 주세요.

## 형식 및 주석 기준

- Java 소스와 테스트에 2칸 들여쓰기와 100자 기준 줄바꿈을 적용합니다. 긴 생성자, 요청 인자, 조건문과 체인 호출을 여러 줄로 구분합니다.
- 주석은 존댓말로 작성하며 기능 책임과 동시성·보안·저장 규칙의 이유를 설명합니다.
- 포맷터가 정리한 import 순서, 줄바꿈, 괄호와 후행 쉼표 이외에 비즈니스 규칙, SQL, API 계약, 마이그레이션은 변경하지 않습니다.
- Prettier 3.6.2와 prettier-plugin-java 2.8.0을 기준으로 사용합니다. 저장소의 `.prettierrc.json`이 공통 옵션입니다.
- Java 포매터는 임시 도구 폴더에 설치하여 Maven 의존성과 분리합니다. Node 실행 시 해당 폴더의 Prettier에 `--plugin <도구폴더>/node_modules/prettier-plugin-java/dist/index.js`를 전달하고 `src/**/*.java`를 대상으로 실행하실 수 있습니다.

## 검증과 커밋

이번 정리 후 별도 PostgreSQL17 컨테이너의 전용 `rufit_test` 데이터베이스에서 Java21/Maven `verify`를 실행했습니다. 전체202개 테스트가 통과했으며 실패·오류·건너뜀은 없습니다. 기존 실행 서버와 DB는 테스트에 사용하지 않았습니다.

커밋에는 정리한 패키지, 주석 보완의 목적, 동작 유지 범위와 검증 결과를 구체적으로 남깁니다. 기존 커밋 이력을 다시 쓰거나 의미 없는 ‘코드 정리’ 한 줄 메시지만 남기지 않습니다.
