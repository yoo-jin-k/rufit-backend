# 친구 관계 서버 검증

전용 rufit-auth-test-db에서 신규 테스트 회원만 사용했습니다. 사용자 기존 친구를 변경하지 않았습니다.

- V29: 신청 이력, 대칭 친구 관계, 방향별 차단을 별도 테이블로 저장합니다.
- 신청 UUID 재시도로 중복 신청을 막고 양방향 동시 신청은 한 건만 남깁니다.
- 수신자만 수락/거절, 발신자만 취소할 수 있습니다. 무관한 계정에는404를 반환합니다.
- 차단 시 친구·대기 신청을 원자적으로 정리하고 검색에서 양방향 제외합니다. 차단 해제나 오래된 수락 재시도는 친구를 복원하지 않습니다.
- 신규 통합 테스트5개: 신청/수락 재시도와 타계정 권한, 차단 후 늦은 수락, 차단 대기 취소와 방향 권한, 거절/취소/교차 신청, 동시 반대 방향 신청.
- Java21 전용 PostgreSQL 전체 Maven verify 및 패키징 성공. 결과 수치는 target/surefire-reports와 실행 로그에서 확인했습니다.
- 아직 신고 운영·응원·푸시·게시물 공개 권한·최종 프론트 화면 연동은 완료하지 않았습니다. 실제 제공자 로그인 검증도 별도입니다.
