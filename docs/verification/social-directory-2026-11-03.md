# 친구 검색 디렉터리 검증

2026-11-03. Java21 Maven 컨테이너와 rufit-auth-test-db의 전용 rufit_test DB를 사용했습니다. 개발 preview DB와 사용자 자료는 변경하지 않았습니다.

## 구현
- V28: 검색용 공개 식별자·닉네임·검색 허용·버전 테이블. 기존 비공개 프로필을 자동 복사하지 않습니다.
- 인증 principal로 설정 소유자를 결정하고 응답에는 내부 계정명을 넣지 않습니다.
- 검색은 명시적 허용 회원만 대상으로 하며 자신을 제외합니다. 검색어 길이·페이지 상한·와일드카드 문자 처리를 검증합니다.
- 동일 설정 재시도는 버전을 증가시키지 않고 다른 내용의 오래된 버전은409입니다.
- 계정별 트랜잭션 잠금으로 동시 최초 등록의 공개 식별자를 하나로 유지합니다.

## 결과
- 새 PostgreSQL 통합 테스트5개 통과: 비공개 제외/공개 철회, 계정 분리/응답 최소화, 재시도·버전 충돌, 검색·페이지 경계, 동시 최초 생성.
- 전체 mvn -B verify: 210개, 실패0/오류0/건너뜀0, 패키징 성공.
- 생성된 OpenAPI에 /api/v1/social/directory/me와 /search 경로가 포함됨을 확인했습니다.

## 미완료
친구 신청·수락·거절·차단·신고·알림은 별도 후속 구현입니다. 차단 연동 이전에는 실제 서비스 친구 검색 화면으로 공개하지 않습니다. 기존 개발용 친구 목록을 실제 계정 자료로 변환하지 않았으며 배포하지 않았습니다.
