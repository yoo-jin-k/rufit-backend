# 여러 종목의 최근 세트

`GET /api/v1/workouts/previous-sets?exerciseIds={UUID},{UUID}`는 선택한 종목별로 가장 최근 완료 운동의 세트를 한 번에 반환합니다. 루틴을 시작할 때 이전 기록을 참고하는 용도이며 현재 운동의 세트나 무게를 변경하지 않습니다.

입력은 종목 ID 1~50개입니다. 중복 ID는 첫 등장 순서대로 하나만 반환합니다. 전체 요청의 ID 개수를 먼저 제한하며, 존재하지 않거나 다른 사람의 비공개 종목이 하나라도 있으면 404입니다. 본인 보관 종목의 과거 기록은 조회할 수 있습니다. ID 없는 자유 입력의 이전 기록은 기존 `exercise-history?exerciseName=...`를 사용합니다.

응답은 `items[{exerciseId,exerciseName,record}]`입니다. `exerciseName`은 현재 카탈로그 이름이고 `record`는 `workoutId`, `finishedAt`, 원래 순서의 `sets`입니다. 세트 내부 이름은 운동 당시 스냅샷을 유지합니다. 완료 기록이 없으면 종목 항목은 존재하고 `record`가 null입니다.

각 종목에 대해 완료시각 내림차순, 같으면 운동 ID 내림차순으로 하나의 본인 운동을 선택합니다. 그 운동에서 해당 종목의 모든 세트를 반환합니다. 다른 종목이 섞인 같은 운동이나 서로 다른 운동이 종목별로 선택될 수 있습니다. 진행 중·취소·삭제된 기록과 타 계정의 기록은 제외하며, 최신 기록 삭제 후에는 남아 있는 이전 완료 기록을 조회합니다.

카탈로그 권한 확인과 최근 세트 조회는 반복 읽기 트랜잭션에서 묶어 수행합니다. 종목마다 개별 API/DB 조회를 반복하지 않고 두 묶음 SQL을 사용합니다. 프론트의 `api.previousSets(ids)`는 조회 결과를 타입으로 제공하며 화면에서 이전 무게를 적용하는 선택 UI는 아직 연결하지 않았습니다.
