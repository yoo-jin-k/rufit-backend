# 비공개 프로필 기본 저장

현재는 본인 프로필 저장 단계입니다. 사진 업로드·공개 프로필·검색 노출·피드 공유·외부 로그인 제공자 연결은 포함하지 않습니다. 응답 `visibility`는 항상 `PRIVATE`이며 공개 설정을 바꾸는 API는 없습니다. 운동 기록 저장으로 프로필이나 게시물이 자동 생성되지 않습니다.

| 요청 | 동작 |
| --- | --- |
| GET /api/v1/profile | 본인 프로필 조회. 아직 없으면 404 |
| POST /api/v1/profile | 프로필 생성. Idempotency-Key UUID로 재시도 보호 |
| PUT /api/v1/profile | 버전을 확인하고 본인 프로필 수정 |

생성 본문:

```json
{"nickname":"루핏유저","bio":"운동을 기록하는 중입니다.","experience":"BEGINNER","goals":["STRENGTH"]}
```

수정 본문은 `{"version":0,"profile":{...생성과 같은 필드...}}`입니다. 모든 수정은 같은 계정의 버전을 검사하며 충돌은 409입니다. 같은 생성 키의 재시도는 현재 프로필을 반환하고, 다른 생성 키로 두 번째 프로필을 만들 수 없습니다. 키는 계정별 범위입니다.

- 닉네임: 앞뒤 공백 정리 후 2~30자. 현재 표시 이름이며 고유 사용자 핸들은 아닙니다.
- 소개: 0~500자, 줄바꿈 보존. 빈 문자열로 지울 수 있습니다.
- 운동 경력: BEGINNER / INTERMEDIATE / ADVANCED 또는 null(미설정). 사용자가 선택하는 자기 소개 값입니다.
- 운동 목표: GENERAL_FITNESS / STRENGTH / MUSCLE_GAIN / WEIGHT_MANAGEMENT 목록. 빈 목록으로 지울 수 있습니다.
- 인증 principal의 계정으로만 조회·저장합니다. 본문의 ownerName, 공개 상태로 소유권이나 공개 여부를 바꿀 수 없습니다.

사진 저장 위치나 실제 개인정보를 데모에 입력받는 UI는 아직 만들지 않았습니다. 운영 서비스의 로그인 제공자와 계정 삭제 정책을 연결한 뒤 해당 단계를 검증해야 합니다.
