# 회원 탈퇴 API v1

## 요청
`DELETE /api/v1/account` (로그인 필요, 본문 없음)

| 응답 | 의미 |
| --- | --- |
| 204 | 탈퇴 완료. 같은 접근 토큰과 갱신 토큰은 바로 거절됩니다. |
| 401 `SESSION_EXPIRED` | 로그인하지 않았거나 이미 탈퇴한 계정 |

## 지우는 것
- 계정, 이메일·카카오·Google 로그인 수단, 세션과 갱신 토큰, 이메일 인증 요청
- 이 계정에 합쳐진 예전 계정과 합치기 기록
- owner_name으로 저장한 운동·루틴·직접 만든 종목·측정값·프로필·목표·단위·휴식 설정
- 소셜 회원 행과 함께 프로필 사진·소개, 친구·신청·차단, 오운완과 사진, 좋아요, 응원, 알림, 운동 중 상태

## 남기는 것
- 신고 기록(`social_reports`)은 부정 이용 방지를 위해 `member_deleted_at`을 기록하고 **6개월(183일)** 뒤 지웁니다.
  서버가 1시간마다 확인해 지웁니다(`rufit.account.report-purge-delay-ms`).
- 개인정보처리방침의 보유 기간과 이 값이 같아야 합니다.
