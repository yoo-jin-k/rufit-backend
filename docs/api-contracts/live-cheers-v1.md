# 친구 운동 상태와 응원 v1

인증 principal의 계정으로만 실행합니다. 친구 화면에서 닉네임을 저장한 회원에게 적용합니다.
운동 기록 저장과 별개의 상태 신호이며, 운동 중량·위치·사진은 전송하지 않습니다.

| 메서드·경로 (/api/v1/social) | 요청 | 응답 |
|---|---|---|
| GET /live | 없음 | 200 `{sharing:false,workoutId:null,items:[],received:[]}` |
| PUT /live/sharing | `{enabled:true}` | 204 |
| PUT /live/mine/{workoutId} | `{active:true}` | 204 |
| POST /live/{memberId}/{workoutId}/cheer | 없음 | 204 |

- sharing 초기값 false. 명시적으로 켠 뒤에만 운동 상태 공개. 끄면 즉시 본인 상태 삭제.
- workoutId: 1~120자 영문/숫자/하이픈/밑줄. 본인 기기 운동 ID이며 서버 운동 기록의 존재를 요구하지 않습니다.
- active:true는 공유 허용 상태에서 마지막 갱신시각을 서버 시각으로 갱신합니다. false는 해당 운동만 종료합니다. 다른 운동을 지우지 않습니다.
- 앱 활성 상태에서 30초마다 갱신하며 120초 이상 갱신되지 않은 상태는 숨깁니다. 종료/백그라운드는 종료 요청을 보냅니다. 통신 실패 시 만료가 안전망입니다.
- items: 현재 수락된 친구 + 양방향 차단 없음 + 공유 허용 + 유효 상태만 최대100명. `{memberId,nickname,workoutId,sent}`.
- received: 현재 내 상태의 운동에 받은 응원 최대100개 `{memberId,nickname}`. 상태가 없으면 빈 배열.
- 응원은 친구/양방향 차단을 전송 시 다시 확인하고, 최초 전송에는 활성 운동도 확인합니다. 이미 성공한 응원의 동일 재시도는 종료 후에도204입니다. 같은 발신자·수신자·운동에 한 번만 저장하며 재시도도 중복 알림을 만들지 않습니다. 자신에게 전송400.
- 응원 저장과 WORKOUT_CHEER 알림 생성은 같은 트랜잭션입니다. 알림에는 workoutId가 포함됩니다. 수신자만 열람/읽음 가능하며 친구 해제·차단 시 기존 알림 규칙에 따라 숨김/제거됩니다. 눌렀을 때 응원한 친구 프로필로 이동합니다.
- 서버 회원별 잠금을 친구 관계 변경과 같은 순서로 획득하여 차단 경쟁을 방지합니다.
- 오류: 미인증401, 입력오류400, 회원 미등록/비친구/차단404, 만료·종료된 운동 또는 공유꺼짐409. RFC ProblemDetail `{type,title,status,detail,instance}` 공통 형식.
- 비공개 설정은 계정별 서버 저장. 로그아웃 후 상태는 최대120초 이내 만료되며 별도 OS푸시는 이번 범위에 없습니다.

## v1.1 공개 범위와 운동 볼륨 (2026-11-17)
기존 요청은 그대로 동작합니다. 새 필드는 모두 선택입니다.

| 메서드·경로 | 요청 | 설명 |
|---|---|---|
| GET /live | 없음 | 응답에 `scope`가 추가됩니다. 각 item에 `friend`, `volume`이 추가됩니다. |
| PUT /live/sharing | `{enabled:true, scope:"FRIENDS"\|"PUBLIC"}` | scope를 생략하면 지금 값을 유지합니다. 처음 켜는 경우 기본값은 FRIENDS입니다. |
| PUT /live/mine/{workoutId} | `{active:true, volume:3240}` | volume은 진행 중 운동에서 완료한 세트의 무게×횟수 합계(kg)입니다. 0~10,000,000. 생략하면 이전 값을 유지합니다. |

- scope FRIENDS: 지금처럼 친구에게만 보입니다. 기존에 켜 둔 회원은 모두 FRIENDS로 유지합니다.
- scope PUBLIC: 친구가 아닌 로그인 회원에게도 보입니다. 사용자가 PUBLIC을 직접 고른 경우에만 적용합니다.
- items: 친구는 `friend:true`, 친구가 아닌 PUBLIC 회원은 `friend:false`입니다. 양방향 차단은 항상 제외합니다.
  정렬은 친구 먼저, 같은 묶음 안에서는 volume 내림차순, 같으면 닉네임 순입니다. 최대 100명입니다.
- 응원은 나에게 보이는 회원(친구 또는 PUBLIC)에게 보낼 수 있습니다. received도 같은 기준입니다.
- 지금 PUBLIC으로 운동 중인 회원은 검색을 허용하지 않았어도 GET /social/members/{id}로 프로필을 열고 친구 신청을 보낼 수 있습니다. 운동이 끝나면(120초) 다시 검색 허용 여부를 따릅니다.
- volume은 서버가 검증하지 않는 표시용 값입니다. 운동 기록에는 저장하지 않습니다.
