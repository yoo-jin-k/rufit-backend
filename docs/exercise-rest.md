# 종목별 권장·개인 휴식시간

종목 검색/상세에 nullable recommendedRestSeconds를 제공한다. 종목마다 다른 추천값을 가지고, 사용자 지정은 별도 계정·종목 설정으로 저장한다.

| API | 동작 |
| --- | --- |
| GET /api/v1/exercises/{id}/rest | 추천·개인·적용 시간과 출처, 버전 조회. 설정 행 생성하지 않음 |
| PUT /api/v1/exercises/{id}/rest | version, mode=PERSONAL/RECOMMENDED, restSeconds 설정 |

PERSONAL에는 0~3600 정수 초가 필수다. 0은 자동 휴식 끄기다. RECOMMENDED는 restSeconds를 생략하거나 null로 보낸다. 설정 초기 version=0, 저장부터 증가한다. 추천으로 되돌려도 행과 버전은 남아 과거 요청이 최신 선택을 덮어쓰지 못한다. 요청 owner 필드는 사용하지 않으며 인증 소유자만 접근한다. 다른 사람의 개인 종목은 404다.

적용 순서는 개인 지정 → 종목 추천 → 계정 공통 기본값(미설정90초)이다. 직접 등록한 종목에는 임의 추천을 생성하지 않는다. 보관된 종목의 기존 기록/설정은 유지한다. 종목 이름 문자열로 다른 종목의 추천을 추정하지 않는다.

세트 완료 API의 restSeconds는 선택 입력으로 확장했다. 생략/null이면 적용 순서대로 결정하고, 명시한 초는 그 요청에만 우선 적용한다. 완료 취소는 추천 조회 없이 기존 대상 휴식을 제거한다. 이미 완료한 세트를 다시 완료하거나 설정을 변경해도 진행 중 휴식의 절대 종료시각을 다시 만들지 않는다. 다음에 새로 완료한 세트에 새 설정을 적용한다.

## 초기 추천값과 근거

짐워크에서 종목별 휴식과 ‘권장 휴식시간 사용’ 옵션을 관찰했다. 각 종목의 실제 추천 숫자는 확인하지 않았으며 아래 값은 루핏의 조정 가능한 초기값이다.

- 스쿼트·데드리프트·프론트 스쿼트: 180초
- 덤벨컬·트라이셉스푸시다운·사이드 레터럴 레이즈·크런치: 90초
- 나머지 기본 카탈로그의 복합 동작: 120초
- 임의 신규/개인 종목: 추천 미설정, 개인값 또는 계정기본값 사용

[IUSCA 2021 입장문, 휴식 간격 권고](https://journal.iusca.org/index.php/Journal/article/download/81/140/5323)의 복합관절 동작 2분 이상, 단일관절/일부 머신 동작 60~90초 범위를 참고했다. 위 개별 종목 매핑과 180초 선택은 제품 초기 설정이며 문헌이 각 종목에 이 숫자를 직접 지정한 것은 아니다. 훈련 강도·목표에 따라 사용자가 조절할 수 있다. 개인 건강 상태에 대한 자동 처방은 아니다.

V23: exercises 추천 열 + exercise_rest_preferences 테이블. 기존 계정 공통 설정과 이미 진행 중인 휴식은 변경하지 않는다.

## 현재 휴식 10초 조절

POST /api/v1/workouts/{id}/rest/adjust 에 version과 seconds(-10 또는10)를 보낸다. 다른 소유자404, 이전버전409, 휴식없음/종료운동409, 잘못된 조절값400이다. 남은 시간을0~3600초로 제한하며 만료 후+10은 현재부터10초다. 운동 진행/정지·완료 세트는 바꾸지 않는다. 응답 유실 또는409 후에는 GET으로 버전/마감시각을 확인한다. 최신 version으로 바꿔 동일 조절을 자동 재적용하면 휴식이 두 번 늘어날 수 있으므로 금지한다. 새 사용자 조작이 있을 때만 별도 요청한다.
