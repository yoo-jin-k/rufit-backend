# 기본 휴식 시간

인증된 본인의 `GET /api/v1/preferences/rest`는 `version`, `defaultRestSeconds`를 반환합니다. 아직 저장하지 않았다면 버전 0, 기본 90초를 반환하며 조회만으로 DB 행을 생성하지 않습니다. 프로필 생성 여부와 무관하게 사용할 수 있습니다.

`PUT /api/v1/preferences/rest`에 마지막으로 읽은 `version`과 0~3600 사이 정수 `defaultRestSeconds`를 보냅니다. 0은 자동 휴식을 시작하지 않는 설정입니다. 최초 저장은 버전 0이며 저장할 때마다 버전이 증가합니다. 오래된 버전은 409로 거절되므로 다시 조회하여 사용자가 선택한 값을 확인한 뒤 저장해야 합니다. 응답을 잃은 경우에도 조회해서 저장 결과를 확인하며 오래된 요청으로 덮어쓰지 않습니다.

이 설정은 다음 세트 완료 입력에 사용할 기본값입니다. 완료 API의 명시적인 `restSeconds`는 계속 필수이며, 앱에서 설정을 읽어 해당 값으로 보냅니다. 이미 진행 중인 운동·휴식 종료시각·세트별 명시 입력은 설정 변경만으로 바뀌지 않습니다. 기본 90초는 초기 제품 기본값으로, 디자인과 사용자 설정 정책에 따라 변경할 수 있습니다.

V19 테이블은 인증 principal의 계정 식별자로 분리됩니다. 실제 PostgreSQL 테스트는 조회 부작용 없음, 계정 분리, 버전 충돌, 입력 범위, 진행 중 휴식 보존을 확인합니다.
